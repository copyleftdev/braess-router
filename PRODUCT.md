# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and Canvas; user accepted the recommended code-first approach. No build step or provider credentials. Suitable for static hosting, including GitHub Pages.

## Users
Developers evaluating Braess Router and its Jev integration.

## Product Purpose
Explain semantic routing through a traffic visualization and lead visitors to the public GitHub repository.

## Positioning
Jev selects a handler category; Poise distributes requests across that category's endpoints. Braess bounds admission and retains uncertainty conservatively.

## Capabilities and Constraints
Single-server alpha with loopback handlers. No production performance or general model-accuracy claim. Visualization uses historical synthetic outcomes with illustrative timing, never live telemetry.

## Brand Commitments
Braess Router, black and white, elegant particle motion with meaningful shapes, exact typography, and a prominent GitHub link. Independent of TypeSafe AI.

## Evidence on Hand
Verified historical gateway-durable-load-v1 experiment: 29,767 request outcomes, three phases (normal, overload, recovery). Source SHA256 manifest verifies requests and summary. Individual arrival timestamps are absent. No credentials or original request text may ship with the landing page.

## Product Principles
Show the mechanism. Distinguish measurements from illustration. Keep the public surface concise. Make the motion understandable without color and optional for reduced-motion users.
